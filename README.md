## Notes

- These files are presented as coursework examples, not production-ready libraries.
- Some examples depend on Windows-specific headers, a classroom starter project, or external dependencies and may not compile in isolation.
- Generated IDE caches, compiled binaries, large recordings, and assignment instruction documents were deliberately omitted.
- Code and project configuration are provided in their original form, with file organization adjusted for readability.

## Academic integrity

Only publish this repository if your course rules allow sharing past assignments and the work is yours to distribute. The repository may contain classroom starter code; review and remove any code you do not have permission to publish.

## M178 biological modeling

Each homework folder contains a Jupyter notebook (`simulation.ipynb`) and a report (`report.pdf`). The Homework 2 report has email addresses redacted for privacy. Check course rules and collaborators' permission before making reports and starter notebooks public.

### Homework 3 note

The Homework 3 report discusses solver warnings at extreme binding parameters. Interpret these exploratory simulations with that limitation in mind.
